# Random Graphs – Mathematical Analysis and Simulation

## Overview
This repository contains a written paper and the Python simulation that numerically confirms our statments and proofs.
Project developed in the scope of the seminar paper for  Maß- und Wahrscheinlichkeitstheorie (en. measure and probability theory).

## Repository Structure
- `paper/` – the academic paper (PDF and LaTeX)
- `simulation/` – Python code used for our simulation

## Simulation
The simulation explores properties of random graphs and their mathematical
behaviour under different parameters.
